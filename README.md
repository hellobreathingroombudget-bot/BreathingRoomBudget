# BreathingRoomBudget

Permanent image storage for Instagram carousels (hosted via raw.githubusercontent.com).

## Naming and order (always)
- Folder: `week-YYYY-MM-DD/` (the Monday of that week), then `day-NN/` (01 = Monday).
- Files: `slide-01.png`, `slide-02.png`, ... = the exact order slides are posted. `slide-01` is the cover/hook, the last slide is the CTA.
- `manifest.json` in each day folder lists every slide, its role (cover, body, cta), the original Canva page number, and the Canva design id. Upload to Buffer in manifest order, never by Canva page order.
